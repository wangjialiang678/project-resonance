# 设计文档：克隆解耦技术方案 v2c

> 版本：v2c | 日期：2026-03-16 | 状态：已实现

## 一、设计目标

将声音克隆从识别主流程中解耦，实现：
1. **静默首次克隆**：用户第一次录音（≥5s）时自动后台克隆，不阻塞 ASR+TTS
2. **克隆与识别并行**：ASR 用 WebM（快），克隆用 WAV（后台），互不干扰
3. **设置页手动管理**：保留完整的克隆/清除/重新克隆入口
4. **换人快捷操作**：使用页一键清除，下次录音自动重新学习

```
│   ├── useAudioRecorder()
│   ├── useStepfunASR()

    └── VoiceClonePanel ── 手动克隆 UI（录音/上传/试听/清除）
```

### 2.2 数据流

```
使用页 — 录音流程：
  录音 → 停止
  ├── 主线程：WebM → ASR → TTS 朗读（<2s）
  └── 后台（仅首次 ≥5s）：WAV → cloneVoice API → voiceId 持久化

设置页 — 手动克隆流程：
  朗读一句话 / 上传音频 → cloneVoice → 试听 → 完成

换人流程：
  使用页点「换人」或设置页点清除 → 清除 voiceId → 下次录音重新学习
```

## 三、详细设计

### 3.1 UsagePage 静默克隆逻辑

```typescript
const handleStop = useCallback(async () => {
  setFlowState('processing');

  const needClone = !voiceId;
  const result = await stopRecording({ includeWav: needClone });

  // 后台静默克隆：首次且 ≥5s
  if (needClone && recDuration >= 5 && wavBlob) {
    void onCloneVoice(wavBlob)
      .then((vid) => {
        if (vid) toast.success('已学习你的音色，下次将用你的声音朗读');
      })
      .catch(() => null);
  }

  // 主线程 ASR + TTS（不被克隆阻塞）
  const text = await transcribe(webmBlob);
  await onSpeak(text);
}, [...]);
```

关键点：
- `includeWav` 仅在 `!voiceId` 时为 true，克隆后永远跳过 WAV 转换
- 克隆用 `void`（fire-and-forget），不阻塞 ASR+TTS
- 克隆失败静默忽略，下次再试

### 3.2 UsagePage UI 状态

| 状态 | 显示 |

## 五、兜底策略

| 场景 | 处理 |
|------|------|
| 首次录音 < 5s | 只做 ASR+默认音色，不触发克隆 |
| 克隆 API 失败 | 静默忽略，继续用默认音色，下次再试 |
| 克隆 API 超时（>30s） | AbortController 中断，isCloning 重置 |
| voice_id 过期 | 已有自动回退 + 清除机制，下次录音重新克隆 |
| 换人 | 使用页「换人」或设置页清除，下次录音自动学习新声音 |
